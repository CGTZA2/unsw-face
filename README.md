# Local Face Test Recreation

Open `index.html` in a desktop browser to run the app.

What this version changes:

- Keeps the public UNSW face-test flow local.
- Stores no data on a server.
- Lets you download results as a CSV at the end.

GitHub Pages:

- The repo includes `.nojekyll` for static-file hosting.
- The repo includes `.github/workflows/deploy-pages.yml` for Pages deployment.
- After pushing, enable Pages in the repository settings and set the source to `GitHub Actions`.
